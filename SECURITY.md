# Security and privacy reports

Please do not post API keys, meeting recordings, transcripts, voiceprints or
personal file paths in public issues. Reproduce a problem with minimal example
data when possible. Use GitHub's private vulnerability reporting when enabled
for this repository; otherwise open an issue containing only a general problem
description and a request for a private reporting channel.

The application stores meetings locally. Cloud transcription and the Codex
assistant send the relevant input to the provider configured by the user.
See [privacy and permissions](docs/PRIVACY.md) for the current boundaries.
