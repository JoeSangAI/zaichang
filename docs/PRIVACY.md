# 数据与权限

在场在 Mac 上保存会议资料。转写、原文整理、自动标题、翻译与纪要使用百炼服务；助理与概览使用 Codex。是否发送、发送什么，取决于你选择的功能。

## 按功能看数据流

| 功能 | 本机保存 | 外部处理 |
| --- | --- | --- |
| 仅录音 | 音频、音源与会议元数据 | 不启动云端转写 |
| 录音并转写 | 音频、转写文字与进度 | 配置的 ASR 服务接收音频 |
| 人物手动确认 | 会议中的姓名修订与确认记录 | 确认操作在本机保存；后续整理可能使用这些姓名作为上下文 |
| 原文整理与说话人整理 | 整理结果与进度 | Qwen 接收所需音频片段、转写、人物名单与术语提示 |
| 自动标题 | 会议标题 | Qwen 接收本场转写与相关术语提示 |
| 中文翻译 | 原句对应的译文 | 开启后，Qwen 接收待翻译的英文转写文字，包括本场补译内容 |
| 会议纪要 | 用户保存的 Markdown 文件 | Qwen 接收本场最终转写、笔记文字，以及生成时手动选择的参考文件文字 |
| 跨会议声纹 | 确认声音记忆用途后保存本机声纹资料，使用文件权限保护 | 本机识别 |
| 笔记 | 文字、图片及其关联信息 | 相关笔记文字可能用于 Codex 助理，或在生成纪要时发送给 Qwen |
| 助理对话与主动跟进 | 工作区、任务状态与本机 Codex 历史 | 会议文字、用户问题与读到的相关项目内容进入 Codex 模型服务；外部工具按自身配置处理 |
| 会议概览 | 结构化结果与来源引用 | 本场原文通过 Codex 生成概览 |
| 已有原文、笔记与音频导出 | 你选定位置的文件副本 | 保存副本不发起外部分享；生成新纪要另走上列云端流程 |

云端服务的留存、训练与地域规则以你所用服务及账号设置为准。

纪要参考资料由你在生成时手动选择，支持文件与文件夹中的 PDF、TXT、Markdown。读取出的文字会发送给百炼。笔记与参考资料用于背景理解，不会附加成导出纪要的额外章节，但可能影响纪要的表达与重点。

## 服务与计费

转写与 Qwen 处理使用你自己的百炼凭据，按服务提供方的实际用量与计费规则消耗额度；翻译、标题、整理与纪要会产生各自的调用。Codex 助理和概览使用本机 Codex 登录账号的订阅或使用额度。两类服务分别计费，在场不提供共用的免费额度。

## 系统与助理权限

音频采集需要 macOS 授予对应的麦克风或电脑声音录制权限。没有权限的声音来源无法正常采集。

用户主动发起的助理任务使用 Codex 的 `workspace-write` 沙箱与 `on-request` 审批策略；当前工作目录是用户主目录。**在场不是只限于会议文件的文件访问沙箱。** 在 Codex 允许的范围内，助理可能读取本机文件，也可能执行用户要求的文件修改。项目文件中被读取的内容可能发送给模型服务。

需要审批的命令、文件变更或其他请求会显示在应用中。工作区内获准的操作不一定每次弹窗。具体行为取决于本机 Codex 配置与运行版本。

主动跟进默认关闭；开启后的观察与跟进任务使用只读沙箱。关闭时取消未完成的主动任务，用户已经接手的对话可以继续。

会议文字与笔记作为参考资料传入，不视为执行指令。会议中有人提到“发给客户”，不会自动构成用户授权。

## 凭据与声纹

云端转写需要使用你自己的凭据。按[安装指南](INSTALL.md)配置，不要把凭据写入源码、问题反馈或截图。

Codex 通过自己的登录与运行环境管理账号。在场的 App Server 传输层不读取或复制 Codex 凭据文件。

声音记忆通过人物确认与用途设置管理。当前声音记忆以本机文件保存，目录和文件限制为当前用户访问，未做应用层加密。同一系统账户下具有文件访问权限的程序仍可能读取它。人物识别结果可能有误，保留人工核对与纠正入口。

## 删除、导出与独立副本

会议库中的删除、音频清理与人物资料管理是不同操作。请按界面说明选择范围：删除原音会影响后续复听或重新转写；保留的文字仍可独立阅读。

已导出的文件、系统备份、用户自行同步的副本，以及 Codex 自己保存的对话历史各自独立。删除在场中的会议，不会自动删除这些副本或撤回已经发给服务提供方的数据。

## 公开问题反馈

反馈时提供系统版本、应用构建信息、错误提示和复现步骤即可。截图请遮盖参与者姓名、会议内容、账号、项目路径与凭据；未经授权的音频和逐字稿不应上传到公开 Issue。
