# 使用在场

[安装与配置](INSTALL.md) · [数据与权限](PRIVACY.md) · [返回首页](../README.md)

## 安装后打开新版

默认安装位置是 `~/Applications/在场.app`。安装完成后，在访达中选择「前往 → 前往文件夹」，输入 `~/Applications`，再打开其中的「在场」。如果安装时指定了其他目标位置，请从该位置打开。

桌面上的旧应用副本，以及 Dock 中指向旧副本的图标，不会自动变成新版。先退出旧版，将旧图标从 Dock 移除，再把新安装的「在场」拖入 Dock；移除 Dock 图标不会删除会议资料。

更新已有独立版时，会议资料继续保留在 `~/Library/Application Support/ZaichangStandalone`。其他版本使用的资料目录不会自动迁入此目录。

## 确认录音模式，再开始记录

新录音会同时采集麦克风与全部电脑声音，无需切换应用。电脑上的其他应用、播放器与通知也可能被收录。线下面谈通过麦克风收音；手机通话需要打开外放，由 Mac 的麦克风收音。

选择「仅录音」时，应用保存音频，不生成实时原文。选择「录音并转写」时，应用会把音频发送至配置的云端转写服务。开始前确认录音模式，并在 macOS 提示时允许麦克风与电脑声音录制权限。

录音期间可暂停、继续或结束。出现转写中断时，先查看界面状态；录音保存与转写进度是两件事。未完成的转写可以从保留的录音中重试。

## 用助理衔接会前、会中与会后

在开始录音前即可打开助理、说明会议目标，并提供项目文件所在位置。开始录音后，当前讨论会接上会议原文与笔记。你可以随时提问，也可以在停止录音后继续对话。

例如：

> 请先读我指定的项目说明，列出这次会议需要确认的三个问题。

> 刚才说要调整交付时间。对照项目计划，哪些依赖也需要确认？

> 根据这次会议，整理已经确认的事项和仍有分歧的问题，分别附上原文依据。

项目文件的位置需要真实存在，且在 Codex 可访问的范围内。助理引用本地文件时可以直接打开；文件夹引用会进入访达。

每场会议共用一个助理对话，用户提问与助理提醒按时间排列。旁听只读；你明确交办后，助理可以生成图片、制作文件或执行获授权的操作，需要确认时会在对话中询问。输入框上方显示简短工作状态与停止入口。图片按正文顺序展示，可复制或另存为原图，其他附件可以展开查看。

## 旁听由你开启

「旁听」默认关闭。开启后，助理持续读取新的会议定稿和配置中的项目背景，自行判断何时提醒。旁听时也可以直接提问。关闭开关会中断旁听；会议暂停或结束后，不再续开旁听。界面只显示助理提醒与回答，不显示推理或工具过程。

## 三个标签，各做一件事

| 标签 | 用途 |
| --- | --- |
| 助理 | 提问、讨论、查看任务进展与跟进结果 |
| 概览 | 查看根据本场已完成转写整理的议题、要点与明确的下一步 |
| 笔记 | 写下自己的记录，也可粘贴图片 |

概览只使用本场原文，不混入助理的外部研究。原文有变化后，概览可能显示等待更新。没有明确说出的负责人、日期或决定，不应被当成已确认事项。

助理的默认名字是小满。在助理的菜单里选「助理名字…」可以换成你想叫的名字，提问、旁听和后台任务都会用这个名字。

拖动侧栏边缘调整宽度。在较窄窗口下，可收起侧栏，先阅读原文。

## 纠正名字，保留原话

先核对原文，再核对发言人。麦克风、电脑声音和应用名称表示声音来源；一个来源可能包含多人。

名字没有足够依据时会留待确认。打开发言人更正，会看到一张张待确认的人物卡片：听一句原声，确认建议的名字或填上名字；也可以合并、归入其他人。跨会议识别是另行授权的功能，需要保存本机声纹资料。识别建议仍应按实际发言核对。

AI 整理稿与原文分开。整理可改善阅读，涉及金额、日期、承诺和人名时，应回看原文或录音。

## 对照英文原句看中文翻译

说话人栏旁的「中文翻译」开关，开启时为绿色，关闭时为灰色。开启后逐句翻译已完成的英文转写，并补译本场已有的英文内容；原文仍保留。翻译结果随会议保存在本机。

翻译调用你配置的百炼服务，需要联网并消耗该账号的用量。关闭后停止继续请求翻译。已开启翻译时，原文导出也可带上已经完成的译文。

## 把记录带回项目

在会议库中打开已保存的会议，可以继续查看原文与笔记，并导出会议文件。原文导出为文本文件；个人笔记可导出为 Markdown，笔记图片随文件保存。音频有单独的导出入口。

导出的文件是独立副本。删除应用里的会议不会自动清理你已经复制到其他位置的文件。

## 生成有原文依据的会议纪要

从导出入口选择会议纪要。生成前可以选择本地 PDF、TXT、Markdown 文件或文件夹，作为理解项目与专名的背景；也可以不添加资料直接继续。PDF 需要包含可提取的文本。

纪要包含固定六部分：**概要、议题与结论、明确决定、明确待办、未决问题、关键原话**。决定、待办和引文会检查原文依据；没有明确说出的负责人或时间留空。会中笔记帮助确定重点，参考资料帮助理解背景，两者不会作为会议发言附加到导出的纪要中。

纪要通过你自己的百炼凭据调用 Qwen 生成，保存为 Markdown。它与助理中的「概览」使用不同的生成入口和服务：概览由 Codex 整理本场原文，纪要可在生成时加入你选定的背景资料。

## 常见问题

**能直接录 iPhone 电话吗？**
当前方式是手机外放、Mac 麦克风收音。应用没有直接获取 iPhone 通话音轨的入口。

**为什么有录音，却没有实时文字？**
先查看是否选择了「仅录音」，再检查转写凭据、网络与服务状态。仅录音模式不会产生实时原文。

**安装 Codex 就能使用我在桌面版看到的所有连接器吗？**
在场使用本机 Codex App Server。可用工具以这个运行环境的配置与授权为准；桌面应用中的连接器需要分别确认可用性。

**不开旁听，能正常向助理提问吗？**
可以。开关只控制主动观察与跟进，手动提问和会议概览有自己的入口。

**可以完全离线使用吗？**
仅录音与查看已保存内容可以在本机进行。云端转写、原文整理、自动标题、翻译、纪要，以及 Codex 助理、概览与旁听需要对应服务连接。
